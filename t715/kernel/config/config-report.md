# The release configuration translated to arm64: symbol by symbol

Generated by `build-arm64.sh` from `config-release-arm32`, `config-arm64.changes`,
`config-arm64.gone` and `config-arm64.new`.  Reference: the release configuration of the 32-bit
kernel (1292 built in, 69 modules).  Result: 1385 built in, 70 modules.

How to read it.  `make olddefconfig` on the release file under `ARCH=arm64` keeps every symbol
it can and drops the rest (the "plain" column).  Our own lines are then applied.  A symbol is
"unchanged" when the release builds it and the final configuration builds it the same way.
